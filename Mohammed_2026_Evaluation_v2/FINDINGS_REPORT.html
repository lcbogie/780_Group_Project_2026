The short version

Ordinal FIFA rank, combined with roster composition, is the best predictor we've found

Our best-performing model out of eleven tested combines a team's literal FIFA rank position (1st, 2nd, 3rd...) with the share of its roster playing in Europe's top-5 leagues. Scored against the real, concluded 2026 World Cup, this combination lands at RMSE 0.931 -- clearly ahead of every Ranking-Points-based model, every roster-only model, and a neural network, all clustered between RMSE 1.04 and 1.33.

The one part of our proposal we still can't close out: benchmarking against Nate Silver's "Pele" system. That data is paywalled — see § Still Open below.

Revision note

An earlier round of this evaluation concluded that a simple roster-composition metric (t5league) beat FIFA Ranking Points, full stop. Colby has since found that Ordinal Rank — a team's literal rank position, not its raw points score — is a meaningfully stronger FIFA-based input than Ranking Points was. This report reflects that revision: the old conclusion is superseded, not merely refined. See § Findings, item 1.

Notebook by notebook

What the code in each notebook actually does

Pipeline A — Roster-composition & ordinal-rank models, scored on 2026

ranking_points_and_t5league_modeling_EVAL_COPY.ipynb
2010–2022: World Cup goals + FBref roster-by-league counts, joined to FIFA Ranking Points and Ordinal Rank at each pre-tournament date. 2026: wc_2026_model_input.csv (real outcomes, both FIFA rank forms, already merged).
  • Builds Y: standardized scoring margin, 128 rows (2010–2022)
  • Builds RP, OR (Ordinal Rank), t5league, and 5 individual league-share features, all standardized
  • Fits 8 OLS regressions via np.linalg.lstsq -- every combination of {RP, OR} × {alone, +t5league, +individual leagues}, plus t5league/individual leagues alone
  • Re-standardizes the 2026 features using the training mean/std
  • Scores all 8 linear models + the neural network from Pipeline B against real 2026 outcomes
Best model: Ordinal Rank + t5league (aggregate), RMSE 0.931 / MAE 0.759 — the strongest result this project has produced, and it generalizes.

Pipeline B — Filling in the Neural Network

ranking_points_and_t5league_modeling_NN_COPY.ipynb
Same 2010–2022 training features as Pipeline A (Ordinal Rank + 5 league shares -- the strongest feature set per the notebook's own revised conclusion). No 2026 data touches this notebook directly — its fitted network is re-used and tested out-of-sample back in Pipeline A.
  • TensorFlow has no wheel for this environment's Python version — substituted scikit-learn's MLPRegressor
  • One hidden layer, 8 units, ReLU, lbfgs solver, random_state=0
  • Fit on all 128 rows, no held-out split
  • Compares its RMSE to the best linear model on the same features
In-sample RMSE: 0.555, vs. 0.835 for the best linear model. Overfit, again Out-of-sample on 2026 (scored in Pipeline A): RMSE 1.153, worse than 7 of the other 8 models.

Pipeline C — Extending the baseline suite to 2026

mohammed_baseline_models_2026_EVAL_COPY.ipynb
wc_2018.csv (train), wc_2022.csv (test), fifa_ranking-2024-06-20.csv at both pre-tournament dates, then wc_2026_model_input.csv as a second, independent test set.
  • Aggregates match-level rows into one row per team (goals for/against, games played, scoring margin)
  • Joins each team to its FIFA rank & points on the pre-tournament ranking date
  • Fits historical mean, 2 linear regressions, a depth-3 decision tree, and a 500-tree random forest — all on 2018 only
  • Verifies its regenerated 2022 numbers against the midway report's originally recorded results
  • Runs the same, un-refit models forward onto real 2026 results
Best model, both years: Linear regression on (ordinal) FIFA rank — RMSE 0.900 (2022) and 1.049 (2026). This notebook already used ordinal rank, not points, so it was unaffected by Colby's revision -- and its own finding is consistent with Pipeline A's.

What it means

Cross-cutting findings

1

Ordinal Rank, not raw Ranking Points, is the right way to use FIFA's rankings

Switching from FIFA Ranking Points to a team's literal Ordinal Rank meaningfully improved every model that used it, both in-sample and on real 2026 data. This supersedes the project's earlier finding that roster composition alone beat "FIFA rank" -- it beat a poorly-scaled version of FIFA rank. Properly represented, FIFA rank is competitive with, and combined with roster composition, better than, our custom metric.

2

Combining metrics is genuinely worth it now

The old analysis found combining roster composition with Ranking Points barely helped. With Ordinal Rank instead, the combined model clearly beats either input alone out-of-sample (0.931 vs. 0.973 for Ordinal Rank alone) -- real evidence the two capture different signal.

3

The neural network overfits again -- more dramatically this time

In-sample it beat the best linear model by an even wider margin than before (0.555 vs. 0.835). Out-of-sample, it dropped to 1.153 -- worse than 7 of 8 linear models. Two neural networks, two confirmed overfitting results.

4

Raw FIFA Ranking Points is the weakest input across the entire project

True in the original analysis, true in the revised one, true in the baseline suite. The one finding that never changed.

5

A separate approach on the team reaches a compatible conclusion

Henmi's independent XGBoost/Poisson match-outcome model (predicting win/draw/loss rather than scoring margin) found that a simpler Poisson baseline (68.7% accuracy) beat XGBoost (63.9%) on real 2026 matches -- the same "simpler model wins" pattern showing up in a completely different methodology and target variable.

Elsewhere on the team

A complementary approach: match-outcome classification

Henmi built a separate pipeline (Henmi_Player_Stats_XGBoost/) predicting match outcomes (home win / draw / away win) rather than tournament-long scoring margin, using ELO ratings plus individual player performance stats (club and international goals, assists, passes, shots, tackles) pulled from an API-football source. Trained on 3,728 matches from 2018 through just before the tournament, tested on the 104 real 2026 World Cup matches.

Unfinished business

Still open: the proposal's actual benchmark

Our proposal set a specific bar: beat Nate Silver's “Pele” system on the 2026 World Cup. We could not close this out, for two real reasons:

  • Paywalled data. Silver's per-team PELE ratings and projections sit behind a Silver Bulletin subscription. We did not pay for access to work around this.
  • Mismatched target variable. PELE outputs championship/advancement probability, not a projected scoring margin -- converting one to the other would be its own modeling decision, not a free lookup.

If anyone on the team has (or gets) Silver Bulletin access, pulling PELE's per-team projected goals and re-running this comparison is the one piece that would let us honestly answer the proposal's original question. Full detail in ranking_points_and_t5league_modeling_EVAL_COPY.ipynb.
